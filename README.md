# SARVESHWAR FITNESS

Open `index.html` directly or use VS Code Live Server.

## Edit prices and membership benefits
Open `script.js` and edit the `CONFIG.membershipPlans` array. The four plans are exactly 1, 3, 6 and 12 months, with separate cardio/non-cardio values.

## Add real photos
Put the actual gym photos into `/images/` using the filenames already referenced by `index.html`.

The site intentionally does not invent prices, discounts, reviews, equipment brands, member counts, or unconfirmed facilities.
